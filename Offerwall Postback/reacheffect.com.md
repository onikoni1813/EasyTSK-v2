You can config your Conversion Postbacks here using 2 types.
1: URL, this will allow you to apply a url which we have to request per conversion using the available macros in the clickable box below.

2: META/Facebook: this require you to to add the Meta PixelID and Token, but this will only work when the incoming visitor came directly from a click on a ad served in Meta as Meta apply automatic the fbclid as parameter on the destination Url which we catch and store as "clickid".

As additional option you can enable "Postbacks per ConversionType" and than you are able to apply multiple postbacks.
